# 169 · Plan 0004 R0.3 and R0.3a · Local Rust API

The local Axum process serves `GET /api/health` on loopback, port 3003 by
default. It can validate a Node-issued Better Auth cookie and read the
matching unexpired session. Node continues issuing and renewing sessions.
The session query has checked-in SQLx offline metadata. See
[RT-4](../spec/runtime.md).

- Node parity passed for four cookie cases, five error statuses and health.
- Rust left both checked session rows unchanged and sent no cookies.
- Native Axum (3003) and the isolated renderer (56304) both returned 200.
  The host's Docker listener occupied 3002, and the Docker daemon timed out,
  so this rehearsal used native processes. The local Compose rehearsal
  remains part of R0.6.
