# 175 · Plan 0004 N4 · Acceptance criteria

Task editors can create, edit and reorder acceptance criteria. An authorized
human reviewer of an active run can check or uncheck them. Checked text
requires a reviewer to uncheck it before editing.

- Migration 0046 has a deferred position constraint for atomic reordering.
- Rust uses audited transactions and the existing task edit/review actions.
- Browser verification covers edit, reorder and review in three locales.
  It fixtures Rust criteria and review responses and uses real Node sign-in.
- The Apuch Compose overlay gives Rust the existing PostgreSQL hostname and
  read-only TLS CA. Contract: [AA-5.8](../spec/agent-access.md).
