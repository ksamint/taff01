# 170 · Plan 0004 R0.4 · Audited Rust transactions

`taff-db` now has a transaction helper for a verified person or agent.
It sets the transaction-local actor, takes the shared workspace lifecycle
lock, and locks the member row for agent writes. The operation checks
authority inside the transaction. Existing PostgreSQL triggers write
activity and send `taff_changes` on commit.

- In a disposable schema, the Node and Rust writes produced the same
  activity and event fields after excluding generated identifiers and time.
- A forced rollback preserved the row and published no event.
- The contract is [AU-3](../spec/audit.md). No route calls the helper yet.
