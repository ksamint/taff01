# 172 · Plan 0004 R0.7 and N1 · Agent run costs

The Rust cost endpoints total all runs of one task or project within its
workspace. The response includes failed run count, failed cost and duration.
Projected tasks and projects require finance access. Standalone tasks require
a workspace admin. Task detail and project finance show the localized USD
total. The Rust DTO emits the shared browser schema.

- 13 signed-session requests verified totals, failed and rework runs, admin
  and member access, guest denial and workspace isolation.
- Six browser cases passed in the three supported locales, including the
  unchanged finance visibility spec. The new browser case mocks cost data.
- The api-rs image uses Rust 1.97.1. Static Compose and Caddy validation
  confirmed internal port 3003 and the narrow `/api/costs/*` matcher.
