## What works

- **Route.** `/projects/[id]?view=mind` renders the lazy `MindView`
  (`src/components/mind-view.tsx`, `src/styles/mind.css`); `mind` left
  `PLANNED_VIEWS`, which is now empty. The map is the workspace's (D8), so
  every project of a workspace shows the same map; the current project is
  the default target of a validation task.
- **Canvas.** Hand-rolled SVG, no library: rings at 80 + 85 × layer (four
  named rings, more appear when a node sits on ring 5–10), angles clockwise
  from the top, dots sized by strength (1–5) and filled per ring (ink,
  muted ink, outlined, gold), a gold dot for nodes with evidence, ↑/↓ for
  momentum, curved links through the mid radius (supports solid,
  contradicts dashed in warning colour). Selecting a node lights its whole
  upstream and downstream path and dims the rest (prototype `anc`/`desc`).
  Pan by dragging, wheel zoom at the cursor, two-finger pinch, zoom and fit
  buttons. Labels never render below 12 px on screen; when that would
  crowd the rings (zoom < 0.55, i.e. phone fit) only the inner ring and
  the lit path keep labels. Hit targets are at least 44 px on screen.
- **Overview panel** (nothing selected): rising nodes (six strongest with
  momentum > 0), cooling nodes, and all sources with evidence coverage
  ("14 / 21 個節點有外部佐證" on Northwind), each source with its host tag,
  cited-by count, edit and (admins) archive / restore. The prototype's
  static "AI 洞察" summary is **not** ported; a footnote says notes and
  strengths are written by team members, not generated by AI.
- **Node panel**: ring, title, momentum badge, strength meter
  (`role=meter`), the note under 洞察 / 機會 labelled as a team member's
  note, evidence (sources with title link `rel="noopener noreferrer"`,
  host, summary; the prototype's warning when none), 源自 and 影響 lineage
  buttons, direct links with an editable kind select and a remove button,
  an add-link form (direction, node, kind), and 驗證.
- **Create and edit.** Labelled dialog forms (native `<dialog>`: focus
  trap, Escape, focus restored) for nodes (title, ring, angle — defaulting
  to the middle of the widest free gap on the ring — strength, trend,
  note) and sources (citation, optional http(s) link checked on the
  client and the server, summary). "New source as evidence" creates a
  source and links it to the node in one step. Nodes and sources are
  archived, never deleted; admins can show archived rows and restore them.
- **Turn into a validation task.** The button opens a confirm form with the
  title ("驗證機會：{node}", editable), project (current project, or none)
  and due date (today + 5 in the person's zone). `POST
  /api/mind/nodes/:id/task` creates a real task owned by the signed-in
  person, due 23:59 that day in their zone, with the node's note as
  description; the panel then shows "已建立任務 · NW-12 …" and 打開任務.
  Nothing is attributed to an agent.
- **Mutations** (`src/lib/mutations/mind.ts`): every write is optimistic
  on both cached maps (active and with archived rows), rolls back on
  error, sends the row's `version` (nodes, sources, edges), and toasts with
  撤銷 whose undo calls the inverse API: create → archive (admins), edit →
  PATCH the previous fields with the new version, archive ↔ restore, link
  edit → PATCH the old kind, link removal → POST it again, evidence add ↔
  remove. A link to a pair already linked (either way) is caught on the
  client (這兩個節點已有連結) and the server's 409 shows the same text.
- **Keyboard and screen readers.** 以列表顯示 replaces the canvas with
  every node grouped by ring (title, trend, strength, evidence and link
  counts); ↑/↓ move between rows, Enter opens the node and moves focus to
  its heading; 返回總覽 moves focus to the overview heading. Every node is
  reachable and editable without a pointer. Selection changes are
  announced in a polite live region; toasts use the app's live region.
  The canvas is `role="img"` with a label pointing to the list.
- **Backend (additive).** Migration `0026_m18_mind_edge_version` (`ADD
  COLUMN version integer DEFAULT 1 NOT NULL`, `ADD CONSTRAINT … CHECK`,
  both in the additive-migration test) and `PATCH /api/mind/edges/:id
  {version, kind}` (`mind:write`, 409 on a stale version), with core
  integration and route tests. No new permission rule; no MCP tool.
- **Strings.** `mind.*` (123 keys) in en, zh-HK (source, prototype table
  where it has the string) and zh-CN; zh-HK checked against the §2.4
  variant list.

## Decisions

- **No undo for a validation task.** Tasks are never deleted or archived
  (no inverse API), so the confirm form is the check and the toast's
  action opens the task instead of 撤銷 (as M17's proposal apply).
- **Undo of a create is admin-only**: it archives, which needs
  `mind:archive` (same rule as M15 companies and contacts). Members get the
  toast without 撤銷.
- **Edges got a version** (additive migration) so their kind can be edited
  under the "every mutation sends version" rule; direction is changed by
  removing and re-adding.
- **Momentum −2..2** shows as 急降 / 降溫 / 平穩 / 上升 / 急升 and ↓↓…↑↑;
  strength as "n / 5" (the prototype's 50–84 score is not stored).
- **Ring names.** Rings 1–4 use the prototype's names (集體潛意識, 文化,
  人群, 場景) and the centre 消費者; rings 5–10 are 第 n 環. They are
  interface strings, not per-workspace data.
- **Source tags** show the URL's host; the prototype's kind (論文 / 行業報告
  / 官方統計) and 限制 caveat are not in the data model.
- **Pan/zoom** reuses `fitView`/`zoomAt` from `graph-layout.ts`; the
  gesture code is a smaller copy of the relations canvas's (a shared hook
  is a later cleanup).

  ring and angle fields are the path today); arrow-key nudging.
- Phone: picking a node on the canvas does not scroll the panel into
  view (the panel sits under the canvas); the list path does focus it.
- Per-workspace ring names and centre label, source kinds and caveats.
- A `mind.get` MCP tool (optional in the plan; agents have no mind path).
- Visual baselines (CI's `visual-baselines.yml`), Lighthouse/LCP runs and
  the M19 288-context accessibility audit.
