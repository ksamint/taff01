# 171 · Plan 0004 R0.6 · Local proxy switch

An isolated Caddy v2.11.9 instance switched `GET /api/health` from Node
to Axum and back. The response stayed HTTP 200 with `{"status":"ok"}`.
While the matcher was active, `GET /api/auth/methods` still reached Node
and returned HTTP 200. A rehearsal-only response header verified each
upstream.

The native rehearsal used loopback-only processes because the local Docker
daemon timed out. Compose execution still needs verification. The
[switch and rollback](../runbooks/deploy.md#local-proxy-switch-rehearsal)
are recorded in the deploy runbook.
