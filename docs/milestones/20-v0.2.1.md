[ADR 0017](../adr/0017-versioned-suggestion-undo.md) records the undo contract.
Migration 0027 adds only four nullable columns: tasks.archived_at,
task_plans.archived_at, suggestions.inverse and suggestions.undone_at. There is
no backfill. Split undo archives only its own untouched generated children;
reschedule undo restores the exact prior plan/due date and archives any new plan.

Existing permission checks require a human owner/admin; agents cannot undo.
Active reads hide archived generated tasks/plans. There is no hard-delete path.
